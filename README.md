# 🚀 vpn-autoinstall — VPN в один клик (3x-ui · VLESS-Reality · Hysteria2)

Один скрипт разворачивает на чистом сервере полностью настроенный VPN: панель **3x-ui** с двумя готовыми каналами и первым клиентом. После запуска вы просто заходите в панель из консоли — там уже всё работает, добавляете остальных клиентов в пару кликов.

Собрано и проверено на боевом сервере (Ubuntu 24.04, hostkey NL).

## Что разворачивается

- **Панель 3x-ui** (фикс. версия `v3.2.8` → Xray-core `26.6.1`) на случайном порту, случайном пути, со случайным логином/паролем и HTTPS.
- **Канал A — VLESS + XHTTP + Reality** (TCP/443): основной stealth-канал, маскируется под `www.microsoft.com`, `fingerprint=chrome`.
- **Канал B — Hysteria2** (UDP/443): резерв на QUIC, обфускация **salamander** + **port-hopping 20000–40000**.
- **Сетевой тюнинг**: BBR + `fq`, увеличенные буферы TCP/UDP — «чтобы летало».
- **Фаервол nftables**: deny-by-default, SSH-safe, блок исходящего SMTP (анти-абуз).
- **Самопроверка**: реально прогоняет трафик через прокси и подтверждает работу.
- **На выходе в консоли**: ссылка на панель, логин/пароль, готовые ссылки и QR клиента.

## Установка (одной командой)

На **чистом** Ubuntu 24.04 / Debian 12 (root, amd64):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/denis-ne-normis/server-init/main/install.sh)
```

Через 2–3 минуты в консоли появятся доступы к панели и QR-код основного канала. Готово.

## Настройка (необязательно)

Параметры задаются переменными окружения перед запуском. Без них берутся разумные значения по умолчанию.

```bash
# примеры
SNI_DONOR=www.twitch.tv \
PANEL_PORT=39000 \
ENABLE_HYSTERIA2=1 \
bash <(curl -fsSL https://raw.githubusercontent.com/denis-ne-normis/server-init/main/install.sh)
```

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SNI_DONOR` | `www.microsoft.com` | Донор Reality (TLS1.3+H2, глобальный CDN). Альтернативы: `github.com`, `www.twitch.tv` |
| `PANEL_PORT` | случайный | Порт веб-панели |
| `VLESS_PORT` | `443` | Порт VLESS+Reality (TCP) |
| `HY2_PORT` | `443` | Базовый порт Hysteria2 (UDP) |
| `HOP_START`/`HOP_END` | `20000`/`40000` | Диапазон port-hopping для Hysteria2 |
| `ENABLE_HYSTERIA2` | `1` | `0` — не поднимать резервный Hysteria2 |
| `BLOCK_SMTP` | `1` | `0` — не блокировать исходящий SMTP |
| `MASQ_URL` | `https://www.bing.com/` | Маскировка Hysteria2 под реальный сайт |
| `FIRST_CLIENT` | `client-1` | Имя первого клиента |
| `XUI_VERSION` | `v3.2.8` | Версия панели (пусто = последняя) |
| `FORCE_REINSTALL` | `0` | `1` — переустановить панель поверх существующей |

## Клиенты

Рекомендуемые приложения: **Hiddify**, **NekoBox**, **v2rayN/v2rayNG**, **sing-box**.
Импорт: скопировать ссылку из консоли → «Добавить из буфера» / отсканировать QR.

> **Важно:** для XHTTP клиент должен быть на свежем ядре Xray (≥ 26.x). Для Hysteria2 port-hopping используйте Hiddify/NekoBox. Подробности и требования — в `/root/vpn-handoff.md` на сервере.

## Где всё лежит после установки

- `/root/vpn-handoff.md` — памятка: доступы, ссылки, требования к клиенту.
- `/root/vpn-setup/secrets.env` — все секреты (chmod 600).
- `/root/vpn-setup/*_qr.png` — QR-коды каналов.
- `/var/log/vpn-install.log` — лог установки.

## Повторный запуск

Скрипт **идемпотентен**: при повторном запуске переиспользует уже сгенерированные секреты (`/root/vpn-setup/secrets.env`) и не создаёт дубликаты inbound'ов. Безопасно гонять снова для донастройки фаервола/тюнинга.

## Требования

- Чистый VPS: **Ubuntu 24.04 LTS** или **Debian 12**, **amd64**, root.
- Открытый исходящий доступ в интернет (для apt и установки 3x-ui).
- Домен **не требуется** (сертификаты — Let's Encrypt для IP, либо self-signed).

## Безопасность

- Панель — только по HTTPS, на нестандартном порту и пути, со стойкими случайными кредами.
- Все секреты генерируются криптостойко (`openssl rand`); примеры в коде — не реальные значения.
- Фаервол по умолчанию закрывает всё лишнее; правило для SSH (22) стоит первым, есть авто-откат при ошибке — заблокировать себе SSH скрипт не даст.
- Рекомендуется после установки включить 2FA в панели.

## Дисклеймер

Для законного использования: приватность, обход цензуры, доступ к своим ресурсам. Используйте на своём сервере и под свою ответственность.

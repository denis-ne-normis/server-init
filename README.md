# 🚀 server-init — свой VPN в пару кликов (VLESS·Reality + AmneziaWG 2.0)

Один скрипт разворачивает на чистом сервере современный VPN с двумя независимыми способами обхода:

- **VLESS + Reality + Vision** — стелс-канал под TLS, совместим с роутерами (xkeen) и Hiddify.
- **AmneziaWG 2.0** — обфусцированный WireGuard (UDP), который DPI не детектит как VPN; для приложения **Amnezia**.

У каждого человека — оба конфига и **персональная страница раздачи** (одна ссылка → QR + оба конфига).

Собрано и обкатано на боевых серверах в РФ-условиях (донор и порт подобраны эмпирически).

## Что разворачивается

- **3x-ui** (пин `v3.2.8` → Xray-core 26.x) на случайном порту/пути, со случайным логином/паролем и HTTPS.
- **VLESS + Reality + Vision** на рабочем порту (по умолчанию `7443`), под выбранный донор.
- **AmneziaWG 2.0** (UDP `39743`) с современной обфускацией (Jc/S1–S4/H-диапазоны/I1) + NAT.
- **N клиентов** (по умолчанию 6) — у каждого VLESS + AWG, общий `subId`.
- **Раздача**: персональная страница `https://IP:2087/p/<subId>` (QR и кнопки для Amnezia и Hiddify).
- **Тюнинг**: BBR + `fq`, увеличенные буферы, `tcp_fastopen`.
- **Фаервол nftables**: deny-by-default, SSH-safe, NAT для AWG, блок исходящего SMTP.
- **Self-test**: реальный прогон трафика через VLESS + (опц.) проверка доступности из РФ.

## Установка (одной командой)

На **чистом** Ubuntu 24.04 / Debian 12 (root, amd64):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/denis-ne-normis/server-init/main/install.sh)
```

Скрипт **спросит**: под какой сайт маскировать (донор Reality) и порт VLESS — предложит проверенные варианты. Через 3–5 минут в консоли появятся доступы к панели и персональные ссылки раздачи.

## Параметры (можно задать заранее через env)

```bash
# свои имена клиентов и фикс. порт панели:
CLIENTS="denis vlad liza parents" PANEL_PORT=39000 \
bash <(curl -fsSL https://raw.githubusercontent.com/denis-ne-normis/server-init/main/install.sh)
```

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SNI_DONOR` | спросит | Донор Reality. Проверенные: `www.nvidia.com`, `www.asus.com`, `www.sony.com`, `www.lg.com`, `www.samsung.com` |
| `VLESS_PORT` | спросит | Порт VLESS. Рабочие в РФ: `7443`, `8880`, `7444`, `7445` |
| `CLIENTS` | `denis vlad liza parents router svyt` | Имена клиентов через пробел |
| `AWG_PORT` | `39743` | UDP-порт AmneziaWG |
| `PANEL_PORT` | случайный | Порт веб-панели |
| `BLOCK_SMTP` | `1` | `0` — не блокировать исходящий SMTP |
| `CHECK_RUSSIA` | `1` | `0` — не проверять доступность из РФ |
| `XUI_VERSION` | `v3.2.8` | Версия панели (пусто = последняя) |

## Одинаковые клиенты на нескольких серверах

Чтобы у людей был один и тот же `subId` (и единая раздача) на разных серверах:
возьми `CLIENTS_JSON` из `/root/vpn-setup/secrets.env` первого сервера и передай его на остальных:

```bash
CLIENTS_JSON='[...]' bash <(curl -fsSL https://raw.githubusercontent.com/denis-ne-normis/server-init/main/install.sh)
```

## Клиенты

- **AmneziaWG** → приложение **AmneziaVPN** (Android/iPhone/ПК). Импорт: «+» → QR или «Файл с настройками».
- **VLESS** → **Hiddify** (включить Xray-core) или роутер (**xkeen**). Импорт: QR / ссылка из буфера.
- На странице `/p/<subId>` есть и то, и другое с инструкциями.

## Где всё лежит после установки

- `/root/vpn-handoff.md` — памятка: доступы + персональные ссылки.
- `/root/vpn-setup/secrets.env` — все секреты (chmod 600).
- `/root/vpn-setup/awg/clients/*.conf` + `dist/*.vless` — конфиги, `*/qr/*.png` — QR.
- `/var/log/vpn-install.log` — лог установки.

## Требования к серверу

- Чистый VPS: **Ubuntu 24.04 (или 22.04) / Debian 12**, **amd64**, root.
- Если у хостинга внешний фаервол — открой там: TCP **22**, порт панели, порт VLESS, **2087**, **2096**; UDP **39743**.
- Домен не нужен (сертификат — self-signed для IP).

## Безопасность

- Панель только по HTTPS, нестандартный порт/путь, стойкие случайные креды.
- Секреты — `openssl rand`; приватный ключ Reality и серверный ключ AWG не уходят клиентам.
- Фаервол закрывает лишнее; правило SSH стоит первым, есть авто-откат при ошибке.

## Дисклеймер

Для законного использования: приватность, обход цензуры, доступ к своим ресурсам. На своём сервере и под свою ответственность.
